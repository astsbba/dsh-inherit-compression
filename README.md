# dsh-inherit-compression

DeepSeek Harness 插件：给长会话做**继承**——到线自动压缩、就地撤回、把记忆交给下一轮。

## 出处与致谢

宿主与客户端骨架来自 [dsh-retrace](https://github.com/yamingmou/dsh-retrace)（v0.4.150，MIT）；
「会话继承」这一整套——锚点、尾部压缩、就地撤回、记忆注入、设置面板——是本项目新增的。
上游版权与许可全文见 `LICENSE`，具体改动范围见 `THIRD-PARTY.md`。

## 它解决什么

上下文一长，模型就开始忘事；换会话重开又会丢人设。这个插件让你在任意一条助手消息上
立一个锚点，之后只把「锚点之后」新增的对话压成一块记忆，撤掉原文、把记忆留在会话里，
下一句话接着聊，语气和记忆都还在。

## 用法

1. 在助手消息那一排按钮里点「继承」——那条消息成为锚点（浅橙色）。
   锚点之后的消息变浅绿；最新一条回复是浅红，点它立刻把锚点之后整段收一次。
2. 每轮结束自动量一次上下文，到设置里的上限就压；也可以在设置里手动触发。
3. 压缩只取锚点之后那段，交给指定模型 + 你写的提示词，压成一块记忆，写进会话里的替换消息。
4. 压完的下一条消息前面会贴一段「近期对话」（最近 N 轮原文，`<对方>`／`<我>` 排版），
   用一次就清；末尾指令可以在设置里改。
5. 再点一次锚点上的按钮冻结；锚点被别的操作遮蔽会自动关闭继承。

压缩没写完之前，同一会话的新请求会排队等待，不拒收、不丢字；压缩期间新发的消息一律不撤。

## 设置（设置 → 继承）

- 总结模型：留空则跟随会话当前模型
- 上下文上限：到这个 token 数触发压缩（默认 600000）
- 压缩提示词：压摘要用的系统提示词（留空用内置）
- 注入提示词：贴在「近期对话」块末尾的指令（留空用内置）
- 压缩上限字数（500–100000）／近期对话条数（0–300）
- 运行日志：最近若干行，出问题先看这里

## 数据

`~/.dsh/inherit-compression/`

- `state.json`：设置、每条会话的锚点与待注入快照（摘要正文不在这里，它就在会话那条记忆消息上）
- `log.txt`：运行日志（超过 200K 自动截半）

## 开发

客户端 bundle 由脚本生成，别手改 `lib/client.bundle.js`：

```
node build-inherit-client.mjs   # build/client.retrace.bundle.js + build/inherit-client.part.js → lib/client.bundle.js
node smoke-inherit.mjs          # 冒烟：模块能注册、apply 被包住
node scrub-upstream-name.mjs    # 需要时：把残留的旧标识再扫一遍
```

宿主改动（`lib/*.js` 里跑在 Node 的那部分）需重启桌面端；只动客户端则刷新页面即可。
